# BharatOS - Filesystem Day 

## What is a File?

A file is a collection of data stored on a storage device.

Examples include:

- Text files
- Images
- Programs
- Configuration files

## What is a Folder?

A folder is used to organize files and other folders.

Folders create a structure that makes it easier to find and manage data.

## What is a Filesystem?

A filesystem is a method used by an operating system to organize and manage data stored on a storage device.

It keeps information about files, directories and where their data is stored.

## Why does an Operating System need a Filesystem?

The operating system needs a filesystem so that users and programs can:

- Create files
- Read files
- Write files
- Delete files
- Create directories
- Find files
