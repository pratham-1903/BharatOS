# BharatOS - Drivers Day 1

## What is a Driver?

A driver is software that allows an operating system to communicate with a hardware device.

Different hardware devices require different ways of communication.

## Why are Drivers Needed?

The operating system needs drivers to communicate with hardware such as:

- Keyboard
- Mouse
- Display
- Storage devices
- Network devices

## Keyboard Driver

A keyboard driver receives information from the keyboard hardware and makes that information available to the operating system.

For example, when a key is pressed, the hardware sends information to the computer.

The keyboard driver processes this information so the OS can understand which key was pressed.

## Future Goal
